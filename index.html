Séquence n°3 : rose des vents

La rose des vents est commandée par V. Pour que le N soit orienté vers le vrai Nord, mesure le cap initial du robot avec une application boussole.

Cap initial :
0° = le robot est déjà dirigé vers le Nord.
90° = le robot est dirigé vers l’Est.
180° = le robot est dirigé vers le Sud.
270° = le robot est dirigé vers l’Ouest.

Commande simple

Avec correction d’orientation Nord

Exemple : si l’application boussole indique que l’avant du robot pointe vers 35°, mets 35 puis clique sur Lancer V35.

Console

Aide rapide

R ou E : lancer l’escalier.

C2, C5, C10, C20 : lancer le cercle.

A35 : mémoriser un cap initial de 35° pour la rose des vents.

V : lancer la rose avec le dernier cap mémorisé.

V35 : mémoriser 35° puis lancer directement la rose.

S : stop général.

D : debug dans le moniteur série Arduino.

Interface BLE compatible avec le code Arduino des 3 séquences.
